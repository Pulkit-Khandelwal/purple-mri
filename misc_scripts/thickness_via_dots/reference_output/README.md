# Reference output

One completed `vis` output illustrates the files generated by the thickness
workflow. The files are anonymized. These outputs were supplied from a different
mask version and are **not expected results for the bundled input masks**.

The reported radius is **1.66439 mm**; thickness is **3.32878 mm** (`2 × radius`).
This is a reference value, not a newly computed or quality-controlled measurement.

| Suffix | Contents |
| --- | --- |
| `_binary.nii.gz` | Tissue mask used for this measurement |
| `_bndmesh_raw.vtk`, `_bndmesh_smooth.vtk` | Original and smoothed tissue boundaries |
| `_skeleton.vtk`, `_skeltetra.vtk` | Skeleton and tetrahedral representation |
| `_thkmap.nii.gz`, `_ctrmap.nii.gz` | Sphere radius and center maps |
| `_dotbin.nii.gz`, `_dotmesh.vtk` | Selected landmark mask and mesh |
| `_dot_thkmap.nii.gz`, `_dot_ctrmap.nii.gz` | Maps sampled around the landmark |
| `_sphere.vtk` | Selected inscribed sphere |
| `_thkmax.txt` | Sphere radius and center |

Open the NIfTI files in ITK-SNAP and the VTK meshes in ParaView.
