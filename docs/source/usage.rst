Usage guide
===================

Start with :doc:`installation` and :doc:`quickstart`. Use :doc:`cli` for all
options, :doc:`inputs` for file conventions, and :doc:`outputs` for result paths.
For direct container commands, see :doc:`docker`. For the remote GUI workflow,
see :doc:`itksnap`; it does not require the local Python/Docker installation.
The historical native entry point is documented in :doc:`legacy`.
